Disney Deep Deinterlacing (DDD)
================================

Source repository:
https://github.com/vincentvdschaft/Disney-Deep-Deinterlacing
Fixed upstream commit: ea3442a2a403b91f950a6f4688e872ed0fe60460
Checkpoint: pretrained_checkpoint/model_state_dict.pt
Checkpoint SHA-256: 4638eba617cce205ca91aacb71199bbffd98907ba0e688c432a7a5b8af64e16c

The DDD.onnx file is converted from the checkpoint above. The network
definition is derived from src/models/deep_deinterlacing.py in the fixed
upstream commit. The ONNX model accepts (1,9,H,W) and returns (1,3,H,W).
